# The Ordinary Verse — Issue archive

**The Ordinary Universe** is the setting and IP; **The Ordinary Verse** is the anthology comic published inside that world.

- [Issue #1](issue-001/README.md) — first anthology, **in production**.

Each issue is a sequential comic book containing multiple normally two-page stories. Internal OU story IDs remain stable for production and references but are not visible as issue numbering on artwork. DaveHub will eventually host an issue reader with a full-spread desktop mode and sequential panels on mobile.
